# 分组和聚合

目标：

- 使用聚合函数：COUNT、SUM、AVG、MIN 和 MAX；
- 使用 Group BY 对数据进行分组；
- 使用 HAVING 子句过滤分组；
- 在同一个查询中使用多个聚合。

## 聚合函数

常见且普遍支持的函数：

- COUNT：计算集合中非空值的个数，适用于任何非空值；
- SUM：对集合中的值求和，值必须是数值类型；
- AVG：计算集合中值的平均值，值必须是数值类型；
- MIN：确定集合中的最小值，值必须是可比较的；
- MAX：确定集合中的最大值，值必须是可比较的。

聚合函数通常出现在 SELECT 值列表中。

```sql
-- 13-1 使用聚合函数进行计数
USE TrackIt;

-- 对 TaskId 进行计数，543个值
SELECT COUNT(TaskId)
FROM Task;

-- 计算总行数，543个值
-- COUNT(*) 统计记录个数
SELECT COUNT(*)
FROM Task;
```

```sql
-- 13-2 对 TaskStatusId 进行计数
-- 返回 532 个值，Task 表的记录数为 543，因为聚合函数省略了 NULL 值
SELECT COUNT(TaskStatusId)
FROM Task;
```

```sql
-- 13-3 对完成的任务进行计算
-- 返回 276
SELECT 
    COUNT(t.TaskId)
FROM Task t
INNER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
WHERE s.IsResolved = 1;
```

## 使用 GROUP BY

如果 SELECT 语句同时包含聚合列与非聚合列，则SELECT语句必须包括 GROUP BY 语句。
如果不使用 GROUP BY 语句，则查询将不会对结果进行适当的分组。
如果存在 WHERE 子句，则 GROUP BY 子句放在 WHERE 后面，ORDER BY 之前。

```sql
-- 13-4 计算每个状态的任务数量：结果按状态进行分组，并计算与每个状态相关联的任务数量。
/*
 *  GROUP BY 语句引用 SELECT 语句中的非聚合列（s.Name）。
 *  如果状态名称为 NULL，则会将其归类在 [None] 下。
 * */
SELECT 
    IFNULL(s.Name, '[None]') StatusName,
    COUNT(t.TaskId) TaskCount
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
GROUP BY s.Name
ORDER BY s.Name;
```

**代码清单 13-5 与书里讲的不同**

```sql
-- 13-5 删除 GROUP BY
SELECT 
IFNULL(s.Name, '[None]') StatusName,
COUNT(t.TaskId) TaskCount
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
ORDER BY s.Name;
/*
 *  Error:
 *  1140 - In aggregated query without GROUP BY, expression #1 of *  SELECT list contains nonaggregated column 'trackit.s.Name'; *  this is incompatible with sql_mode=only_full_group_by
 *  
 * */
/*
 *  原书的解释：
 *  - 使用 LEFT OUTER JOIN 获取所有任务：INNER JOIN 将消除值为 NULL 的 TaskStatusId；

 *  - 别名为聚合值提供有意义的名称。
 * */
```

### 分组和多列

要知道一个状态是否已解决，它的名称是什么？

```sql
-- 13-6 添加 IsResolved 列
-- 这个脚本无法运行
SELECT 
IFNULL(s.Name, '[None]') StatusName,
s.IsResolved,
COUNT(t.TaskId) TaskCount
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
GROUP BY s.Name
ORDER BY s.Name;
/*
 *  1055 - Expression #2 of SELECT list is not in GROUP BY clause and contains nonaggregated *  column 'trackit.s.IsResolved' which is not functionally dependent on columns in GROUP BY *  clause; this is incompatible with sql_mode=only_full_group_by
 *
 *  原因：在核心 SQL 中，SELECT ... GROUP BY 不能选择一个非聚合值或组的一部分的值。
 * */
```

```sql
-- 13-7 在分组中添加 TaskStatus.IsResolved：将其作为 SELECT 列表的一部分加入 GROUP BY 子句中
/*
 *  IsResolved 被添加到 SELECT 中，并包括一个检查其是否为 NULL 的条件，
 *  如果 IsResolved 为 NULL，则它将包括在一个标识为 0 的分组中。
 *
 *  IsResolved 在 GROUP BY 子句中。
 * */
SELECT
    IFNULL(s.Name, '[None]') StatusName,
    IFNULL(s.IsResolved, 0) IsResolved,
    COUNT(t.TaskId) TaskCount
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
GROUP BY s.Name, s.IsResolved -- isresolve 现在是组的一部分。
ORDER BY s.Name;
/*
 *  输出：第一行显示的 IsResolved 的值为 0，而不是 NULL。
 * */
```

### 添加 DISTINCT

DISTINCT 大多通过使用 GROUP BY 对数据进行分组来实现。

```sql
-- 13-8 获取唯一所示项目名称的列表：生成一个包括 26 个唯一项目名称的列表
SELECT DISTINCT
    p.Name ProjectName,
    p.ProjectId
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
ORDER BY p.Name;
```

```sql
-- 13-9 使用 GROUP BY 获取唯一项目名称的列表(和 DISTINCT 相同的效果)
SELECT 
    p.Name ProjectName,
    p.ProjectId
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
GROUP BY p.Name, p.ProjectId
ORDER BY p.Name;
```

## 使用 HAVING

HAVING 子句与 GROUP BY 一起使用，允许根据定义的条件对数据进行过滤，它指定构成分组或聚合的条件。

```sql
/*
 *  在 TrackIt 数据库，要获得分配给工人的任务的预计工时数：
 *  计算每个工人的工时数，并找出总工时数超过 100h 的所有工人。
 *
 *  用到的表：Worker 表、ProjectWorker 表、Task 表
 *  INNER JOIN 可以在所有的关系中使用，只保留匹配的记录。
 *
 *  确定组和选定的值：将 WorkerId 和工人的姓名添加到分组中。
 * */
-- 13-10 过滤查询的初稿
SELECT 
    CONCAT(w.FirstName, ' ', w.LastName) WorkerName,
    SUM(t.EstimatedHours) TotalHours
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Task t ON pw.WorkerId = t.WorkerId
    AND pw.ProjectId = t.ProjectId 
GROUP BY w.WorkerId, w.FirstName, w.LastName;
```

**聚合值不能使用 WHERE 子句进行过滤。WHERE 子句在聚合函数前对数据进行过滤。**

**HAVING 子句只有在存在 GROUP BY 子句时才能使用。其后面跟着一个计算结果为布尔值的表达式，该表达式包括对聚合值的比较。**

```sql
-- 13-11 添加 HAVING：工时大于等于 100 的工人
SELECT
    CONCAT(w.FirstName, ' ', w.LastName) WorkerName,
    SUM(t.EstimatedHours) TotalHours
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Task t ON pw.WorkerId = t.WorkerId
AND pw.ProjectId = t.ProjectId
GROUP BY w.WorkerId, w.FirstName, w.LastName
HAVING SUM(t.EstimatedHours) >= 100
ORDER BY SUM(t.EstimatedHours) DESC;
```

## SELECT 语句运行的顺序

SELECT 语句的关键字按以下顺序求值：
1. FROM：确定从哪开始；
2. JOIN ON：连接其他表，并设定表之间的关系；
3. WHERE：对表中的行进行过滤；
4. GROUP BY：按照列，对数据进行分组，并计算聚合；
5. HAVING：按聚合方式对分组后的结果进行过滤；
6. SELECT：决定最终结果的组成部分；
7. DISTINCT：从结果中删除重复项；
8. ORDER BY：对最终结果进行排序；
9. LIMIT：返回最终结果的一个子集。

## 其他示例

```sql
-- 13-12 查询任务的最早截止日期：只用 Worker 表和 Task 表
/*
 *  使用函数 MIN 与 DueDate。
 *  函数 MIN 和 MAX 适用于任何一个可以进行比较和排序的数据类型（数字、日期、时间和字符串）。
 * */
SELECT 
    p.Name ProjectName,
    MIN(t.DueDate) MinTaskDueDate
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
WHERE p.ProjectId LIKE 'game-%'
    AND t.ParentTaskId IS NOT NULL
GROUP BY p.ProjectId, p.Name
ORDER BY p.Name

```

```sql
-- 13-13 包括10个或更多任务的项目概述
/*
 *  每个项目的概览：第一个和最后一个任务的截止日期、预计总工时、任务总数和任务平均预计工时
 * */
SELECT 
    p.Name ProjectName,
    MIN(t.DueDate) MinTaskDueDate,
    MAX(t.DueDate) MaxTaskDueDate,
    SUM(t.EstimatedHours) TotalHours,
    AVG(t.EstimatedHours) AverageTaskHours,
    COUNT(t.TaskId) TaskCount
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
WHERE t.ParentTaskId IS NOT NULL
GROUP BY p.ProjectId, p.Name
HAVING COUNT(t.TaskId) >= 10
ORDER BY COUNT(t.TaskId) DESC, p.Name;
```

## 小结

- 聚合函数从多个值中计算出一个单一的结果，源值来自列和其他计算。单独使用时，聚合函数为每个查询结果计算一个值；
- 常见的聚合函数：COUNT、SUM、MIN、MAX 和 AVG；
- GROUP BY 子句是 SELECT 语句的可选扩展，将结果分为不同组。聚合函数可对组进行操作，并为每个组提供一个计算出的单一值；
- HAVING 子句是 SELECT 语句的可选扩展，只当 SELECT 语句包括 GROUP BY 子句时有效，使用聚合值计算布尔表达式；
- 不能在 WHERE 子句中过滤聚合值，因为聚合函数在 WHERE 子句计算完毕后才进行计算。
