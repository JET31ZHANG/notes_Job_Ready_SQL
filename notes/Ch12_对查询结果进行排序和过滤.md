# 对查询结果进行排序和过滤

目标：
- 使用 ORDER BY 子句对查询结果进行排序；
- 使用 LIMIT 控制返回的记录数；
- 使用 DISTINCT 只返回唯一的记录。

## 使用 ORDER BY

### 按照单个列排序

```sql
-- 按照自然顺序排序：按照 Worker 的主键 WorkerId 升序排列。
SELECT * FROM Worker;

-- 12-1 使用 ORDER BY：默认的排序方向是升序
SELECT *
    FROM Worker
ORDER BY LastName;
```

```sql
-- 12-2 使用 ASC：升序
SELECT *
    FROM Worker
ORDER BY LastName ASC;
```

```sql
-- 12-3 按降序排序
SELECT *
    FROM Worker
ORDER BY LastName DESC;
```

```sql
-- 12-4 对 JOIN 表进行排序
/*
 *  在 JOIN 表中进行排序，应使用表名或别名来限定排序列。
 *
 *  此查询显示员工的名字、姓氏和项目名称：
 *  需要连接 Worker 表、ProjectWorker 表、Project 表
 *  每个连接表都具有限定符名称，便于跟踪使用的列和表。
 * */
SELECT 
    w.FirstName,
    w.LastName,
    p.Name ProjectName
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Project p ON pw.ProjectId = p.ProjectId
ORDER BY w.LastName ASC;
```


### 按照多个列排序

```sql
-- 12-5 先按照姓氏排序，然后按照项目名称排序
SELECT 
    w.FirstName,
    w.LastName,
    p.Name ProjectName
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Project p ON pw.ProjectId = p.ProjectId
ORDER BY w.LastName ASC, p.Name ASC;
```

```sql
-- 12-6 更改单个排序项的排序顺序：先按照姓氏降序排序，然后按照项目名称升序排序
SELECT 
    w.FirstName,
    w.LastName,
    p.Name ProjectName
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Project p ON pw.ProjectId = p.ProjectId
ORDER BY w.LastName DESC, p.Name ASC;
```

### 改变列的顺序

```sql
-- 12-7 将项目放在工人之前：按项目排序，然后是工人的姓氏
SELECT 
    p.Name ProjectName,
    w.FirstName,
    w.LastName
FROM Worker w
INNER JOIN ProjectWorker pw ON w.WorkerId = pw.WorkerId
INNER JOIN Project p ON pw.ProjectId = p.ProjectId
ORDER BY p.Name ASC, w.LastName ASC;
```

处理空值

```sql
-- 12-8 打印带有状态的任务信息：打印所有任务的标题及状态的名称
SELECT 
    t.Title,
    s.Name StatusName
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
ORDER BY s.Name ASC;
```

```sql
-- 12-9 将 NULL 值排在最后
/*
 *  添加了一个 ISNULL 调用：
 *  - 第一个分组排序：状态名称是否为 NULL，结果以非空到空的顺序进行排序；
 *  - 第二个分组排序：名称按升序排序。
 *  使空值位于输出的末尾。
 * */
SELECT 
    t.Title
    s.Name StatusName
FROM Task t
LEFT OUTER JOIN TaskStatus s ON t.TaskStatusId = s.TaskStatusId
ORDER BY ISNULL(s.Name), s.Name ASC;
```

## 使用 LIMIT

LIMIT 限制从查询中返回的记录。

```sql
-- LIMIT 子句的基本面形式：
LIMIT [Row offset], [Number of rows]
/*
 *  LIMIT 是 SELECT 语句中的最后一个语法元素。
 *  [Row offset] 指数据库引擎从哪一行开始计数，
 *  [Number of rows] 指定要在结果中包括的行数。
 * */
```

```sql
-- 12-10 查询有限多个工人信息：按照姓氏降序排序的前 10 名工人
/*
 *  在 TrackIt 数据库中有 100 名工人
 *
 *  LIMIT 的第一个项目为 0（默认值），因此，没有偏移量（从0开始计数）；
 *  LIMIT 的第二个项目为 10，获取并返回 10 行记录。
 * */
SELECT *
FROM Worker
ORDER BY LastName DESC
LIMIT 0, 10;
```

```sql
-- 12-11 不使用行偏移量进行查询
/*
 *  LIMIT 行偏移量是可选的，默认值是 0，可省略。
 * */
SELECT * 
FROM Worker 
ORDER BY LastName DESC
LIMIT 10;
```

```sql
-- 12-12 使用偏移量
/*
 *  从第10条记录开始
 * */
SELECT *
FROM Worker
ORDER BY LastName DESC
LIMIT 10, 10;
```

```sql
-- 12-13 使用超出范围的偏移量
/*
 *  偏移量设置为超过可用记录的数量，结果为空。
 * */
SELECT *
FROM Worker 
ORDER BY LastName DESC
LIMIT 200, 10;
```

## 使用 DISTINCT

只查看结果列表中的不同内容

```sql
-- 12-14 列出所有具有任务的项目
SELECT 
    p.Name ProjectName,
    p.ProjectId
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
ORDER BY p.Name;
/*
 *  ProjectId 和 ProjectName 值是重复的
 * */
```

```sql
-- 12-15 列出所有有任务的项目
/*
 *  DISTINCT 从查询结果中删除重复的记录
* */
SELECT DISTINCT
    p.Name ProjectName,
    p.ProjectId
FROM Project p
INNER JOIN Task t ON p.ProjectId = t.ProjectId
ORDER BY p.Name;
```

## 小结

- ORDER BY：SELECT 语句的可选子句，根据一个或多个列值或表达式对结果进行排序；
- LIMIT：SELECT 语句的可选子句，将结果记录限制为原始查询的一个子集；
- DISTINCT：允许只检索与请求匹配的唯一记录，不包括重复的记录。
